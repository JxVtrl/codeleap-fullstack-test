# CodeLeap Fullstack Coding Test

This repository contains the fullstack implementation of the CodeLeap coding challenge.  
It is structured as a **monorepo** with two submodules: one for the frontend (React) and one for the backend (Django).

## 🗂 Structure

This project is organized into:

- [`frontend/`](./frontend): React.js app (submodule)
- [`backend/`](./backend): Django REST API (submodule)

---

## 🚀 Getting Started

### 1. Clone the repository with submodules

```bash
git clone --recurse-submodules https://github.com/JxVtrl/codeleap-fullstack-test

cd codeleap-fullstack-test

# If you already cloned the repository without submodules, run this command to initialize them
git submodule update --init --recursive
```
