# CodeLeap Fullstack Coding Test

This repository contains the fullstack implementation of the CodeLeap coding challenge.  
The goal is to build a simple CRUD application with a frontend in React and a backend in Django.

## 🗂 Structure

This project is divided into two main parts:

- [`frontend/`](./frontend): React.js application that handles the user interface and interactions.
- [`backend/`](./backend): Django REST API that provides the data and CRUD operations.
